# Roadmap

## Goal
Build a technology-independent engineering playbook for designing, operating, evaluating, and commercializing production agent systems.

## Phase 1 — Core runtime patterns (Weeks 1–4)
Study LangGraph, Agno, OpenHands, and Langfuse.

Outputs: state/orchestration patterns, runtime/lifecycle patterns, autonomous execution patterns, observability/evaluation patterns.

## Phase 2 — Execution and interaction (Weeks 5–8)
Study Browser Use, LiveKit Agents, Pipecat, and LlamaIndex.

Outputs: browser execution reliability, realtime/voice architecture, multimodal pipelines, retrieval/knowledge architecture.

## Phase 3 — Workflow and platform comparison (Weeks 9–10)
Study n8n and Mastra.

Outputs: integration/orchestration patterns, TypeScript runtime patterns, build-vs-buy observations.

## Phase 4 — Synthesis (Weeks 11–12)
Compare all projects and design a reference Agent OS architecture.

Final outputs:
- technology comparison matrix
- pattern and anti-pattern catalog
- reference control-plane/data-plane architecture
- enterprise security and observability checklist
- recommended technology-selection rules
- business-pattern observations

## Expansion rule
Do not add more core repositories until the first ten have been completed with the standard methodology. New projects go into a backlog first.
