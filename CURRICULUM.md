# 12-Week Curriculum

## Standard weekly cycle

### 1. Orient
Read README, architecture/design docs, examples, changelog/releases and project positioning.

### 2. Execute
Run one representative example where practical. Record setup cost, dependencies, failure points and runtime behavior.

### 3. Decompose
Identify control flow, state, memory, tools, model boundary, persistence, queues/events, security, observability and deployment model.

### 4. Investigate engineering reality
Review high-signal Issues and PRs, prioritizing comments/interactions, architectural changes, regressions, reliability problems and production pain.

### 5. Extract
Write patterns, anti-patterns, trade-offs and decision rules.

### 6. Translate
Record implications for enterprise delivery and an Agent OS / AgentMine platform.

### 7. Review
Complete the weekly review and decide what should enter the permanent playbook.

## Weekly schedule

1. LangGraph — stateful orchestration and HITL
2. Agno — runtime, teams, memory and serving
3. OpenHands — autonomous action loops and sandboxing
4. Langfuse — tracing, evals and observability
5. Browser Use — browser execution and reliability
6. LiveKit Agents — realtime voice runtime
7. Pipecat — multimodal realtime pipelines
8. LlamaIndex — retrieval, knowledge and agent/data integration
9. n8n — workflow automation and integration boundaries
10. Mastra — TypeScript agents, workflows and production runtime
11. Comparison — cross-project architecture and decision matrix
12. Synthesis — Agent OS reference architecture and implementation backlog

## Weekly deliverables

- repository review
- architecture review
- demo report where practical
- issue/PR notes
- minimum 3 candidate patterns or explicit finding that none qualify
- decision record
- weekly review

Quality is more important than hitting arbitrary pattern counts.
